# Slavic Game Jam Assets

This repository is the shared art, audio, and font library for the game. It is used through Anchorpoint by asset contributors and as the `assets` Git submodule by the Godot project.

## Folders

- `source/art/aseprite/` — editable Aseprite files
- `source/art/raster/` and `source/art/vector/` — editable source art
- `source/audio/sfx/` and `source/audio/music/` — editable sound effects, music, and stems
- `source/fonts/` — font files and their licences
- `derived/` — final exports the game needs; do not edit these manually
- `third_party/` — downloaded packs, readmes, and licences

Use Anchorpoint locking before editing shared binary source files. Keep each asset or pack in its own folder and place its licence alongside it.
